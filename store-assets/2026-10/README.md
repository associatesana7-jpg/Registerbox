# RegisterBox Play Store gallery

Six 1080×1920 opaque JPEG phone assets and a 1024×500 feature graphic. Order: start → application preparation → identity consent → AI guidance → documents → privacy.

The interface is rendered from the mobile `.tsx` screen components at release commit `9ae857f`, using a temporary Expo web capture harness and fictional ABC Foods context. These are not Android-device captures. No production account, identifier or customer record is shown. The app interface is not generated or redesigned; only the surrounding background artwork is generated. Device rendering can vary slightly; validate on the uploaded Android build before final production submission.

Built-in image generation was used for `campaign-background.png`. Prompt: premium vertical 9:16 RegisterBox campaign background; electric blue `#0865F7`, navy `#071946`, pale ice and white; satin sculpted ribbons at bottom/right, clear central area for actual screens, no phones, UI, text, people, logos or badges. Source is preserved in the Codex generated-images directory. `gallery.html` contains the exact campaign headlines and deterministic layout. `contact-sheet.html` provides an overview.

Google requirements checked against https://support.google.com/googleplay/android-developer/answer/9866151. Assets have no rankings, testimonials, awards, government affiliation claims or install calls to action. Connected-provider features are qualified; document verification and government submission are not represented as automatically completed.

Upload status: all six phone JPEGs and the feature graphic were uploaded through the native Chrome file picker. The phone gallery is in 01–06 order and was verified after saving and reloading. The seven new assets containing generated background artwork were selected for Google Play's AI-asset label. The existing app icon was left unchanged. Tablet, desktop and XR assets were not fabricated from phone images.
