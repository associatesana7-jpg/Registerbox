# GST missed-month range calculator

Rules checked against GST portal guidance and CBIC notifications on 29 October 2026. The default calculator is a normal-rule estimate, not portal liability or filing permission. It uses no API and keeps inputs in memory.

The user selects the first missed tax month or the last tax month already filed, the end month, and calculation/filing date. Selecting a last-filed tax month starts the gap in the next month. The submission month is explicitly distinguished from the tax period. Open/not-due periods contribute zero.

Monthly GSTR-1 uses the ordinary 11th schedule from July 2018. Monthly GSTR-3B ordinarily uses the 20th; January–December 2020 small taxpayers use the State-group 22nd/24th. Verified QRMP starts from January 2021 or a later quarter; earlier GSTR-3B remains monthly. Historical GSTR-1 quarterly frequency is separately collected for pre-2021 periods; it does not propagate to a later monthly regime. One switch into QRMP is supported. A touched quarter is included whole once and labeled; arbitrary frequency changes need the history worksheet.

Every return gets its own daily fee and ceiling before sums are produced. Combined central and corresponding State/UT figures: nil category ₹20 daily; otherwise ₹50 daily. From June 2021 or quarter ending June 2021: nil cap ₹500; other cap ₹2,000 up to ₹1.5 crore preceding-year aggregate turnover; ₹5,000 above ₹1.5 crore up to ₹5 crore; general ceiling ₹10,000 above ₹5 crore. Nil definitions differ between GSTR-1 and GSTR-3B. Historical normal ceiling is ₹10,000 where supported, with initial GST waivers and partial 2021 periods left unpriced. Conditional relief is not silently assumed. The UI and CSV expose each cap, applied fee and exact symmetric heads.

Ordinary due dates can be overridden with verified notified extensions. Category, turnover and already-filed exclusions can be corrected per return. An invalid correction hides prior totals, suppresses computed table amounts and disables export until corrected. Unknown priced rows cause an explicit incomplete-total message. COVID periods, old filing restrictions and projections are labeled for review; no amount is called final payable. Turnover remains required for nil returns because historical due dates can depend on it.

Regression examples: January–October 2026 monthly nil at 29 October 2026 = GSTR-1 ₹4,360 + GSTR-3B ₹4,180 = ₹8,540, assuming normal due dates, no relief/previous payments and nil categories throughout. October is not yet due. If January tax period is already filed, February–October gives ₹7,540. Tests verify each return cap at either side of its boundary, independent totals, quarterly schedules, prior filing frequency, early/cancelled unpriced periods and input validation.
