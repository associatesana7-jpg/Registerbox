1. Tally connection

In TallyPrime: F1 (Help) → Settings → Advanced Configuration → Enable HTTP Server. Use the same port here. Older releases may place this setting under F12.

2. Load and verify your company

Keep Tally running and open the company you want to use. Company selection stays explicit for every import.

This check only reads Tally. It does not change your books.

Connection troubleshooting
  • Start Tally and load your company.
  • Enable the Tally HTTP server and match its port.
  • If Tally is on another computer, check the LAN address and Windows firewall.
  • Keep Tally port 9000 private. Phone access uses the secured connector.
  • Company creation, passwords and company loading remain inside Tally.

3. Pair RegisterBox

For RegisterBox web on this PC, use the local address. For a phone, configure a reachable HTTPS address below, then test it.

HTTPS and web settings

Use a trusted HTTPS reverse proxy to the local connector, or upload a matching trusted certificate and key to enable the direct TLS listener. A hostname alone does not create DNS, a certificate or a tunnel.
