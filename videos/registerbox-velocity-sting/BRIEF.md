# RegisterBox velocity sting

## Intent

Create a short, unnarrated product sting in which seven RegisterBox surfaces read as one continuous camera move. The piece should feel precise, fast, reassuring, and distinctly product-led rather than explanatory.

## Stated by the user

- Use the `bs-hyperframes-velocity-sting` skill.
- Feature the RegisterBox app in this repository.

## Inferred for this run

- Square social-feed delivery is the skill's default canvas when no destination is specified.
- Use the repository's own logo and brand assets; do not capture or reproduce third-party UI.
- Use an open/system font substitute so the project redistributes no proprietary font files.
- Keep the film silent unless the user later supplies or approves a music bed.

## Seven slots

- A — RegisterBox mark and wordmark, split into two counter-moving parts.
- B — Sign-in surface entering frame.
- C — The same surface closer, with a business email being typed.
- D — One meaningful number: GST return readiness counting to 100%.
- E — Real primary navigation: Home, AI, Compliance, Documents, Account.
- F — The primary action: arrive at and activate “Start registration,” then reveal its next-step menu.
- G — RegisterBox endcard with “Compliance, under control.”

## Rights position

- Mark and UI language come from the user's local RegisterBox repository.
- No external site capture or third-party product UI is used.
- Typography uses a redistributable local/open fallback rather than a proprietary brand font.
